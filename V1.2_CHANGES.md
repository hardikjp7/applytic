## Deploy Order

### Step 1 — Build the Lambda Layer
```bash
bash scripts/build_layer.sh
```

### Step 2 — Run tests locally
```bash
pip install pytest boto3 pydantic aws-lambda-powertools
python -m pytest tests/ -v --tb=short
```

### Step 3 — CDK deploy
```bash
cd cdk && cdk deploy
```

### Step 4 — Commit to develop → PR to main
```bash
git checkout develop
git add .
git commit -m "feat(v1.2): Lambda Layer, shared middleware, Pydantic, X-Ray, Cognito SES trigger, CloudWatch dashboard"
git push origin develop
```

### Step 5 — Enable Allow auto-merge in GitHub
Settings → General → Pull Requests → check Allow auto-merge
